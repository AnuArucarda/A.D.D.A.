PRODUCT REQUIREMENTS:
1.  **AI Orchestration:** The core of the app should be an AI agent (Claude Sonnet 4.5) that understands the entire porting/building process. It will have terminal access on a build server to execute commands (, , build scripts, etc.), analyze output, and automate decisions.

4.  **AI-Guided Android ROM Builder:** A conversational tool where the AI interviews the user to determine the specifications for a custom Android ROM (based on AOSP, LineageOS, etc.) and then automates the build process.
5.  **Halium Builder:** The initial feature request, now a secondary tool, for building Halium-based ports.
6.  **Custom Recovery Builder:** An automated process for building custom recoveries like TWRP, OrangeFox, or PitchBlack for the target device.
7.  **Root Integration:** The ability to bake in root solutions like KernelSU or Magisk into the built kernels and ROMs.
8.  **Project Management:** Users must be able to save their build configurations as recipes for reuse and export a complete build package (images + scripts) as a zip file.
9.  **UI/UX:** A modern, nostalgic theme inspired by Ubuntu Touch and UBports, with a multi-tabbed interface for each major tool.
